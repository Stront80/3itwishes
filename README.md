# «Три желания» — GitHub Pages

Статическая версия лендинга для публикации через GitHub Pages. Включает адаптивный сайт, политику обработки данных и клиентскую проверку формы.

## Публикация

1. Создайте публичный репозиторий на GitHub, например `tri-zhelaniya-site`.
2. Загрузите **содержимое этой папки** в корень репозитория (файлы `index.html`, `styles.css`, `app.js`, `privacy.html` и остальные — непосредственно в корень).
3. Откройте **Settings → Pages**.
4. В разделе Build and deployment выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем нажмите **Save**.
5. Дождитесь завершения публикации в разделе Actions/Pages. GitHub покажет адрес сайта.
6. Для домена `3itwishes.site` в Settings → Pages укажите Custom domain и настройте DNS у регистратора по актуальным значениям, которые покажет GitHub. Включите Enforce HTTPS после выпуска сертификата.

## Важно: отправка формы

GitHub Pages обслуживает только статические файлы и **не запускает Node.js, не хранит секреты и не отправляет SMTP-письма с сервера**. В этой версии форма проверяет поля и открывает почтовое приложение посетителя с подготовленным письмом на `mailbox@familypost.ru`. Посетителю нужно вручную нажать «Отправить». Это не гарантирует автоматическую доставку и зависит от настроенного почтового приложения.

Если заявки должны автоматически поступать на `mailbox@familypost.ru` без действий посетителя, используйте исходный серверный проект на VPS либо подключите отдельный сервис обработки форм/API. SMTP-пароль нельзя помещать в `app.js`, HTML или публичный GitHub-репозиторий.
